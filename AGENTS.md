# AGENTS.md

## Response style (applies to every conversation)

Be brief. Default to a few sentences, not paragraphs.

- No preamble, no restating the question, no "I'll now...".
- Lead with the answer or the result.
- Use a table or list only when it beats prose.
- Report failures and surprises; skip narrating successes.
- Explain reasoning only when a decision is non-obvious or needs sign-off.
- No closing summaries of work already described above.
